{% elif key == 'vix' %}VIX 的作用

基于 S&P 500 期权计算的未来约30天隐含波动率，常被称为“恐慌指数”。快速上升通常表示市场风险定价和预期波动增加，下降则表示风险情绪趋于缓和。

{% elif key == 'dxy' %}美元指数的作用

衡量美元相对一篮子主要货币的强弱。美元快速走强通常意味着全球金融条件趋紧，并可能对风险资产及美国跨国公司的海外收入换算形成压力，但不能单独作为交易信号。

{% else %}10Y 美债的作用
