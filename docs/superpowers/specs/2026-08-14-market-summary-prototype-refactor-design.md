# “今日市场一句话”原型重构设计

## 目标

以用户提供的 `daily-market-brief-summary-prototype (1).html` 为准，仅重构页面顶部“今日市场一句话”模块的 HTML 结构与 CSS 样式。保持其他模块、页面整体配色、页面宽度及数据生成和渲染逻辑不变。

## 结构映射

沿用现有 `report.market_summary` 数据契约，不新增或修改字段：

- `market`：作为模块的主市场摘要，保留重点文本的强调展示。
- `drivers`：独立为“今日关注”行。
- `action`：独立为浅色背景、左侧强调线的策略提示条，并在展示层补充“策略：”标签。
- 固定来源说明：置于内容区右下方。

模块继续仅在 `report.market_summary` 存在时渲染，历史报告兼容行为不变。

## 视觉设计

使用当前页面既有 CSS 变量和色彩体系，不引入原型中的独立主题变量。模块结构和比例参考原型：

- 卡片采用更舒展的内边距、轻边框和小圆角。
- 图标与正文组成两列网格；正文内部依次为标题、主摘要、“今日关注”、策略提示和来源。
- 主摘要限制合理阅读宽度；“今日关注”使用浅色标签；策略提示使用当前蓝色强调色作为左边框。
- 桌面端来源右对齐；窄屏下保持两列骨架并适当缩小间距、字号，避免横向溢出。

## 修改范围

仅修改：

- `templates/report.html`
- `static/style.css`
- 与该模块直接相关的 `tests/test_renderer.py` 断言

不修改数据 JSON、Python 数据生成逻辑、其他页面模块、全局 `.page` 宽度和颜色变量。构建时由现有渲染流程同步生成 `site/style.css` 与站点 HTML；生成文件不作为源代码手工编辑。

## 验证标准

- 渲染测试验证三个现有字段分别出现在主摘要、“今日关注”和策略区域。
- 验证模块仍位于页头之后、“美国主要指数”之前，旧报告仍不渲染该模块。
- 验证新增结构类和响应式规则存在，且页面宽度与数据逻辑未改变。
- 运行完整测试，并重新渲染站点后检查生成页面。
