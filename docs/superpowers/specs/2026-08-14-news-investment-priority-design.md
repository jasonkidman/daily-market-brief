# 全球重要新闻投资优先改造设计

## 目标与范围

以用户提供的 `daily-market-brief-news-module-preview.html` 为视觉基准，把“全球重要新闻”改为面向长期持有 SPY / Nasdaq-100 投资者的投资影响优先模块。

本次只修改：

- 新闻候选的 AI 筛选、评分、排序与结构化分析规则。
- 新闻结构化输出的程序校验与可信候选映射。
- 全球重要新闻模块的模板、模块内样式及其响应式布局。
- 新闻离线夹具、相关测试与由正常渲染流程生成的站点 HTML/CSS。

不修改今日市场一句话、主要指数、市场环境、市场宽度、回撤加仓预警、数据配置、整体页面宽度、全局颜色变量、字体和其他模块间距。

## 方案选择

沿用现有两阶段新闻链路，不新增模型调用：

1. 程序从 RSS 获取候选并执行确定性去重。
2. 现有 Stage A 将多来源报道聚合为事件，并由程序按来源优先级选择代表文章。
3. 增强 Stage B，使 DeepSeek 针对事件候选完成美国资产相关性判断、传导路径分析、评分、过滤、排序和 Top 8 结构化输出。
4. 程序严格校验模型字段，并根据 `candidate_id` 从候选池映射 `source`、`url`、发布时间、原始标题和程序拥有的事件元数据。
5. 前端只展示已验证和持久化的结构化字段，不重新推断投资影响。

不采用关键词预评分作为主要排序依据，避免硬规则误判隐含的宏观传导关系；不增加“选出后再分析”的第三次模型调用，避免额外成本、失败点和两阶段结论不一致。

## 投资优先筛选原则

Stage B 的目标从资讯热度或当日市场解释力，调整为“未来数周、数月或更长期对美国资产定价的重要程度”。排序优先级如下：

1. 美国宏观、美联储、通胀、就业和经济增长。
2. 美债收益率、财政、美元、信用市场、银行压力、流动性和金融条件。
3. AI 资本开支、AI 商业化、收入利润、算力需求与投资回报。
4. 半导体、HBM、代工、网络、服务器、先进封装、电力、冷却和数据中心基础设施的实质性周期变化。
5. 能通过能源、通胀、供应链、贸易、制裁、航运或风险偏好影响市场的地缘事件。
6. 足以改变行业盈利、资本开支、成本或准入预期的美国监管、税收、关税、贸易和产业政策。

普通产品更新、一般功能发布、普通融资、营销、消费与娱乐新闻、单纯采访、小型非指数相关并购及缺少资产定价路径的事件默认降权或过滤。

同一 `topic_group` 原则上最多两条。重大且彼此独立的系统性事件允许突破，但模型必须在 `selection_reason` 中说明独立影响；不得为凑满八条突破主题限制。高质量新闻不足时允许少于八条。

## 评分与过滤

每个入选事件必须输出整数 `investment_relevance_score`，范围 0–100，概念评分维度为：

- 宏观/政策重要性：0–30。
- 对利率和金融条件的影响：0–20。
- 对 SPY / Nasdaq-100 定价或盈利预期的影响：0–20。
- 对 AI / 科技投资周期的影响：0–15。
- 地缘或系统性风险：0–10。
- 时效性：0–5。

程序只接受 50–100 分的入选新闻。70 分及以上为高优先级，50–69 分可在高质量事件不足时补充；低于 50 分不得进入最终列表。`rank` 必须从 1 连续排列，并按评分非递增排列；同分时顺序由模型依据长期重要性、来源可靠度和新鲜度决定。

## 结构化输出契约

DeepSeek Stage B 严格返回：

```json
{
  "news": [
    {
      "rank": 1,
      "candidate_id": "候选 ID",
      "category": "美联储 / 利率",
      "title_zh": "中文标题",
      "summary_zh": "中文摘要",
      "investment_impact": "完整但克制的资产定价传导路径",
      "focus": "后续需关注的指标或事件",
      "tags": ["Fed", "10Y 美债", "成长股估值"],
      "investment_relevance_score": 92,
      "selection_reason": "内部审核使用的入选理由"
    }
  ]
}
```

模型不得返回或决定 `source`、`url`、`published_at`、`original_title`、`event_summary` 或 `topic_group`。这些字段全部由程序根据可信候选池映射或覆盖。

允许的展示分类扩展为：

- `美联储 / 利率`
- `就业 / 通胀`
- `美国经济`
- `美债 / 美元`
- `金融市场`
- `AI / 资本开支`
- `半导体`
- `地缘政治`
- `政策 / 监管`

## 内容与安全校验

程序校验以下条件，违反时触发现有三次重试，最终仍失败则沿用现有安全降级：

- 新闻数量不超过 8，候选 ID 唯一且来自输入池。
- 排名连续且评分非递增；分数为 50–100 的整数。
- 分类属于允许集合。
- 中文标题、摘要、投资影响、关注点、标签和内部入选理由齐全。
- 标签为 1–4 个简短非空字符串，每个不超过 16 个字符，不接受任意对象或长段落。
- `title_zh` 不超过 70 个字符，`summary_zh` 不超过 180 个字符，`investment_impact` 不超过 220 个字符，`focus` 不超过 80 个字符，`selection_reason` 不超过 120 个字符。卡片密度由生成端控制，不依赖 CSS 截断。
- 投资影响必须包含至少一个明确的资产或金融变量，并使用“→”、条件句或因果连接词表达传导关系；不能确认方向时必须使用“短期资产价格影响有限，暂以观察为主。”，不得强行给出利好或利空判断。
- 同一主题超过两条时，超出部分的评分必须不低于 85 分，并在 `selection_reason` 中包含“主题上限例外”及独立系统性影响说明；否则整次输出视为无效并重试。

程序继续保证 URL 不进入 Stage B 模型输入，最终报告中的 URL 只来自 RSS 候选池。

## 旧报告兼容

历史报告可能只有 `title_zh`、`summary_zh`、`category`、`source` 和 `url`。模板继续安全渲染这些报告：

- 缺少 `investment_impact` 时显示“历史报告未生成结构化投资影响，建议结合原文观察。”
- 缺少 `focus` 时显示“关注：查看原文后续进展”。
- 缺少 `tags` 时不显示标签区域。
- 缺少评分时不在页面上补造分数；评分仅用于筛选和审计，不作为卡片主视觉。

兼容文案只用于旧数据展示，不写回历史 JSON，也不触发模型调用。

## 前端结构与样式

模块标题结构为：

- 主标题：`全球重要新闻`
- 副标题：`Top 8 · 投资影响优先`
- 右侧说明：`优先级：宏观政策 · 利率就业 · 金融 · AI · 地缘政治`

新闻区统一渲染最多八张完整卡片，不再使用前三张大卡加右侧列表：

- 桌面端：4 列，最多两行。
- 中等宽度：2 列。
- 手机：1 列。

每张卡按顺序展示编号、分类、来源、标题、摘要、投资影响、关键词标签、关注点和轻量“查看原文 →”链接。卡片采用当前 `--surface`、`--line`、`--soft`、`--navy`、`--blue` 和 `--muted` 体系，细边框、小圆角、无明显大阴影。卡片使用弹性纵向布局，让标签和底部关注区域自然靠下；不设置固定高度，不截断重要文本，也不制造大块空白。

## 数据流与错误处理

模型成功时，报告 JSON 保存所有新字段，供模板直接展示。Stage A 聚类失败时继续沿用现有基础事件降级并进入 Stage B；Stage B 连续三次校验或调用失败时，`news` 为空、`news_degraded` 为真，并继续显示现有新闻 AI 降级提示。其他行情、回撤、市场宽度和今日市场一句话流程不受影响。

离线夹具补充完整的新字段，但继续明确标注为测试数据，不代表真实新闻或投资建议。

## 验证与验收

自动化测试覆盖：

- 新结构化字段、字符限制、标签、评分阈值与评分排序。
- 分类集合、候选池映射、模型 URL 隔离和程序拥有的事件元数据。
- 同事件唯一、主题集中度例外、低相关性过滤与少于八条输出。
- Prompt 包含美国资产定价优先级、过滤项、完整传导路径和克制判断要求。
- 模板八张统一卡片、标题辅助信息、投资影响、关注点、标签、原文链接和旧报告兼容。
- 桌面 4 列、中等宽度 2 列、手机 1 列及无横向溢出。
- 非新闻模块 DOM 与全局页面宽度、颜色和字体规则保持不变。

完成后运行聚焦测试、完整测试、离线全流程、冒烟检查和正常站点重渲染。最后在相同视口对照上传原型与生成页面，并检查桌面、平板和手机布局；不修改其他模块以追求原型整页一致。
